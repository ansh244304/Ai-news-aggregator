# Newsmania Full Frontend

React/Vite frontend integrated with the existing Newsmania Express/MongoDB backend.

Frontend: http://localhost:4000
Backend: http://localhost:5000/api

## Start
npm install
npm run dev

## Integrated
- Auth: register/login/logout/forgot password
- News list/search/category/details
- AI analysis
- Bookmarks
- MCQs
- News quiz + submission/result
- Daily quiz + submission/result
- User dashboard
- Admin dashboard
- Admin news CRUD
- Admin AI/MCQ actions
- Admin daily quiz

## Backend CORS
The backend should allow:
http://localhost:4000
